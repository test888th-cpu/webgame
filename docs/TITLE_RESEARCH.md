# New game title: preliminary research (no renaming done)

**Status: preliminary search only.**

- **This is not legal clearance.** Every candidate needs a formal trademark search
  (for example the USPTO, EUIPO and Thai DIP registers) and legal advice before use.
- **Not checked:** domains and social handles (no registry lookup was available).
- **Searches:** web searches on 2026-11-17. The repository, website and branding are
  unchanged.

## Why rename

**"Iron Legacy" is already a commercial game:**

- *The Iron Legacy*, a 2D action RPG by the solo developer Static Fluid, released on
  Steam on 2026-03-05.
- Listings: [Kotaku](https://kotaku.com/games/iron-legacy),
  [GG.deals](https://gg.deals/ca/game/iron-legacy/),
  [Gamebrain](https://gamebrain.co/game/iron-legacy-2026).
- It is a similar genre, so the current title carries a real confusion risk.
- Also similar: *The Iron Oath*, a tactical RPG.

**Preliminary shortlist:** **Rivetfall**, **Slagborn**, Smeltgard. These found no
exact game match and have the least-crowded neighbours.

**Next steps before any decision:**

1. A formal trademark search in the target markets.
2. Domain and handle checks.
3. Store searches at release time (Steam, Xbox, PlayStation, Nintendo, Apple, Google
   Play).
