# UnitForge uploads

Upload each UnitForge "Godot 4" export into its own folder here, named with the
asset id the game will use (lowercase, underscores), e.g. `art/unitforge/slime_green/`,
and add an `import.json` next to it. Then run **Actions → Assets → Run workflow →
unitforge-import**. Full steps: [docs/ASSETS.md](../../docs/ASSETS.md).
